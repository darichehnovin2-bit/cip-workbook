# ساخت APK (بدون نصب Android Studio)

1. در github.com یک ریپازیتوری جدید بسازید (مثلاً cip-workbook).
2. روی «uploading an existing file» بزنید و **همه‌ی محتوای این پوشه** (از جمله پوشه‌ی `.github`) را آپلود و Commit کنید.
   اگر پوشه‌ی `.github` آپلود نشد، فایل `.github/workflows/build-apk.yml` را دستی با گزینه‌ی Add file → Create new file بسازید.
3. به تب **Actions** بروید؛ ساخت خودکار شروع می‌شود (حدود ۵ تا ۸ دقیقه).
4. بعد از سبز شدن، وارد آخرین run شوید و از بخش **Artifacts** فایل `cip-workbook-apk` را دانلود کنید.
5. فایل `app-debug.apk` را روی گوشی بفرستید و نصب کنید (اجازه‌ی نصب از منبع ناشناس لازم است).

نکته: این APK از نوع debug است و برای استفاده‌ی شخصی و ارسال به دیگران خوب است.
برای انتشار در گوگل‌پلی یا کافه‌بازار به نسخه‌ی release با امضای اختصاصی نیاز دارید که در صورت نیاز آماده می‌کنم.
